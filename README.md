# Guesser Game

A simple number guessing game built with vanilla HTML, CSS, and JavaScript. Try to guess the secret number between 1 and 20 in just three tries!


## Features

- **Simple UI**: A clean and intuitive interface.
- **Random Number Generation**: A new secret number is generated for every game.
- **Limited Trials**: You have 3 tries (represented by hearts) to guess the number.
- **Helpful Hints**: Get feedback on whether your guess is too high or too low.
- **Win/Loss States**: Clear messages for winning or losing.
- **Restart Functionality**: Easily start a new game with the click of a button.

## How to Play

1.  Click the **"Start Game"** button to begin.
2.  The secret number is between 1 and 20.
3.  Enter your guess into the input box.
4.  Click the **"Submit"** button.
5.  A hint will tell you if your guess is too high or too low.
6.  Guess correctly to win!
7.  If you run out of tries, you lose, and the correct number is revealed.
8.  Click **"Restart"** to play again.

## Technologies Used

- **HTML5**: Structures the game content.
- **CSS3**: Handles all styling, layout, and animations.
- **JavaScript (ES6+)**: Powers the game logic and user interaction.

## Setup

To run this project locally, simply open the `Guesser.html` file in your web browser.
